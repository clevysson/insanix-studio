      Como Baixar, Instalar e Verificar

      Todos os arquivos ficam hospedados no GitHub Releases com hash SHA-256 para você conferir a integridade antes de rodar.

      1. 01

        Confira os requisitos no card

        Cada item da loja tem sua própria aba de Instalação e Requisitos explicando o passo a passo exato antes do download.

      2. 02

        Extraia o pacote completo

        Nunca abra executáveis de dentro do .zip. Clique com o botão direito → Extrair Tudo em uma pasta dedicada.

      3. 03

        Valide o hash SHA-256

        Compare o código SHA-256 exibido na janela do projeto com o arquivo baixado para ter 100% de garantia contra alterações.

      Dúvidas Frequentes

      Os downloads são gratuitos e seguros?

      Sim! Todos os projetos publicados aqui são gratuitos e distribuídos pelo GitHub oficial da INSANIX STUDIO, sempre acompanhados de hash SHA-256.

      O Windows SmartScreen apareceu ao abrir um app novo. O que fazer?

      Programas independentes novos sem certificado comercial pago costumam disparar esse aviso preventivo do Windows. Confira se o download veio deste site oficial e valide o hash SHA-256 na janela do projeto antes de clicar em Mais informações → Executar assim mesmo.

      Como instalar mods sem risco de perder saves?

      Siga exatamente o tutorial dentro do item do mod e sempre faça uma cópia da sua pasta de saves antes de instalar ou atualizar modificações.
