    Como baixar e instalar nossos projetos

    Como hospedamos tudo no GitHub, cada arquivo fica organizado por versão e com passo a passo dedicado dentro do próprio card do projeto.

    1. 01

      Escolha o projeto e leia o guia

      Clique em Ver Tutorial & Baixar no card do projeto para conferir requisitos, versões compatíveis e instruções exatas antes do download.

    2. 02

      Baixe pelo GitHub Releases

      Todos os executáveis, pacotes de jogos e arquivos de mods vêm diretamente da aba oficial de Releases no repositório da Insanix Studio.

    3. 03

      Verifique e execute com segurança

      Extraia os arquivos compactados antes de abrir e, se desejar, confira o hash SHA-256 informado no modal do projeto.

      Dúvidas comuns

      Os downloads são gratuitos e seguros?

      Sim! Todos os projetos publicados aqui são gratuitos e distribuídos pelos repositórios oficiais da INSANIX STUDIO no GitHub, com histórico de versões e hash SHA-256 para verificação.

      O Windows SmartScreen apareceu ao abrir um app ou jogo novo. E agora?

      Programas independentes recém-lançados sem certificado pago de assinatura podem disparar aviso padrão do SmartScreen. Confira sempre se o link veio desta página oficial e compare o hash SHA-256 informado no tutorial do projeto.

      Como instalo um mod corretamente sem perder meu save?

      Abra o card do mod desejado e siga o tutorial específico passo a passo. Sempre recomendamos copiar sua pasta de saves para outro lugar antes de instalar ou atualizar qualquer modificação.

      Preciso doar para baixar os projetos?

      Não. Os downloads são liberados para todo mundo. As doações via Pix ou plataforma internacional são 100% voluntárias para incentivar a continuação dos nossos projetos.
